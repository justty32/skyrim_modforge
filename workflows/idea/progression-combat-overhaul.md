# Idea #21：養成與戰鬥體系擴充

← [ideas 索引](ideas.md)

**發想來源**：PoE 的 Keystone 天賦機制 + D&D 5e 的職業核心特性，兩套設計都把「選擇一個能力就要全面翻新配置」的取捨感做得很好，想在 Skyrim 裡重現這種感覺。

**核心概念**：不只是「加幾個 perk」——而是讓玩家做出**影響整個 build 方向**的結構性選擇，每個核心選擇都要求對裝備、資源管理、戰鬥風格做出對應的配套投資。

---

## 靈感來源

### PoE Keystone 天賦（參考的取捨感設計）

| 天賦 | 機制 | 為什麼有趣 |
|------|------|-----------|
| 異靈之體（Chaos Inoculation, CI） | 免疫混沌傷害，但最大生命值變成 1 | 選了它就必須 100% 投資能量護盾，整套裝備策略翻新 |
| 祭血術（Blood Magic） | 移除所有魔力，技能改消耗生命 | 徹底改變資源管理，不能用常規光環，要靠特殊生命保留 |
| 先祖魂約（Ancestral Bond） | 圖騰上限 +1，但自身技能無法造成傷害 | 玩家變「指揮官」，輸出全靠圖騰，走位/詛咒/誘餌才是正事 |
| 堅毅之心（Resolute Technique, RT） | 攻擊必定命中，但永遠無法暴擊 | 輸出穩定極致，但徹底放棄最高傷害上限的暴擊系統 |
| 異能魔力（Eldritch Battery, EB） | 能量護盾改為保護魔力，技能優先消耗護盾 | 把防禦屬性變成施法資源，讓所有魔力都拿去開光環 |

**共同特質**：每個都是**二選一的不可逆取捨**，而且選了之後整套 build 邏輯要跟著重構。

### D&D 5e 職業核心特性（參考的職業感設計）

| 職業 | 核心機制 | 代表技能 |
|------|----------|---------|
| 野蠻人 | 狂暴（Rage）：憤怒狀態，物理減傷 + 近戰傷害 | 運動、威嚇 |
| 戰士 | 動作如風（Action Surge）：爆發性額外動作 | 運動、特技 |
| 武僧 | 氣（Ki）：連續打擊、格擋、飛簷走壁 | 特技、隱匿 |
| 遊蕩者 | 偷襲（Sneak Attack）：對分心/夾擊目標造成弱點傷害 | 隱匿、巧手 |
| 吟遊詩人 | 吟遊詩人激勵（Bardic Inspiration）：給隊友強化骰子 | 表演、說服 |
| 遊俠 | 宿敵（Favored Enemy）：針對特定種族的追蹤與戰鬥優勢 | 生存、自然 |
| 聖武士 | 至聖斬（Divine Smite）：消耗法術位爆發神聖傷害 | 說服、宗教 |
| 牧師 | 引導神力（Channel Divinity）：奇蹟，視信仰領域而異 | 宗教、醫藥 |
| 德魯伊 | 荒野形態（Wild Shape）：變身野獸，獲得其能力與生命值 | 自然、馴獸 |
| 法師 | 法術書（Spellbook）：抄寫最廣泛法術庫，應變能力強 | 奧秘、歷史 |
| 術士 | 超魔（Metamagic）：改變法術規則（分裂/靜音/延伸等） | 欺瞞、奧秘 |
| 邪術師 | 邪術祈喚（Eldritch Invocations）：高客製化被動 + 魔能爆 | 威嚇、奧秘 |
| 奇械師 | 魔法物品化身（Infuse Item）：將普通裝備注入魔力改造 | 調查、工具熟練 |

**共同特質**：每個職業有**一個定義性的資源/機制**，其他所有選擇都圍繞這個核心資源展開。

## 在 Skyrim 裡怎麼做

### 設計方向

Skyrim 原版 perk 樹已有基礎，但缺乏「選了某個 perk 就要全面調整 build」的 Keystone 感，以及「圍繞一個核心資源展開所有其他選擇」的職業核心機制感。

三個可能的實作層次（由淺到深）：

**層次 A：Keystone perk（取捨感）**
在 CSF 自訂技能樹的末端放幾個「互斥 Keystone」——選了一個就改變整個 build 的基礎假設。例如：
- 「死戰之心」：最大魔力值變成 0，技能改消耗生命（Blood Magic 移植）
- 「鋼鐵之軀」：無法造成暴擊，但攻擊永遠命中（RT 移植）
- 「異靈護盾」：最大生命值變成 1，但免疫毒素並獲得大量魔力護盾（CI 移植）

這層靠 PERK + MGEF（修改 actor value）就能做，CSF 技術可行性高。

**層次 B：職業核心資源系統**
給不同「職業路線」一個專屬資源（除了 HP/Magicka/Stamina）：
- 憤怒值（Rage）：特定動作積累，滿了觸發強化狀態
- 氣（Ki）：每次精準攻擊或格擋積累，消耗驅動特殊動作
- 神恩（Divine Grace）：禱告或行善積累，消耗引發神聖爆發

這層需要 GLOB 追蹤 + Papyrus 事件 + MGEF，難度中等，但更接近「職業感」。

**層次 C：多技能樹互動（完整體系）**
多棵 CSF 技能樹（近戰/魔法/敏捷/信仰…），Keystone 跨樹影響，形成一個完整的自訂養成體系，取代或大幅擴充原版 perk 系統。

難度最高，需要完整規劃才能動手。
