# 已落地 — items / magic（record builders）

← [landed index](README.md)｜對應 [CODE_MAP.items-magic](../../common/code-map/CODE_MAP.items-magic.md)

- **GlobalVariable (GLOB)**：`GlobalSpec`（short/long/float + constant）。
- **Projectile (PROJ) + Explosion (EXPL)**：自訂法術飛行彈+爆，鏈 EXPL←PROJ←MGEF←SPEL。
- **Effect Shader (EFSH)（2026-08-11，offline 完整、未實機）**：`effectShaders[]` 生成 membrane tint + actor sprite particles（純 texture/scalar，零 NIF writer），`magicEffects[].hitShader` / `enchantShader` 接線；palette fallback + 缺 palette loud warning，5 個定向測試。見 `SPEC-magic.md § effectShaders`、`examples/effect_shader.json`、`EffectShaderTests.cs`。
- **MGEF 擴充**（2026-06-13）：`archetype:"Script"`（VMAD 掛 ActiveMagicEffect 腳本，走通用 `scripts[]{targetEditorId:<mgef>}`）+ **DualValueModifier**（`secondActorValue`/`secondActorValueWeight`，一法術扣兩條 AV）。**Health+Stamina in-game 確認 2026-06-13**；**踩坑**：Concentration+Aimed 需 `castingArt`+`projectile` 否則 CTD。
- **FormList (FLST)**（2026-06-13，offline）：`formLists[]`（editorId + items 任意 record ref，順序保留）。FLST **無**獨立 `GetIsInList`，走既有 `*OrList` param（GetItemCount/GetEquipped/GetIsVoiceType/GetInWorldspace 收 FormList）。
- **Hazard (HAZD)**（2026-06-13，offline 完整、未實機）：`hazards[]`（model/radius/lifetime/targetInterval/limit/spell/flags + light/sound/imad/impactDataSet）。兩種用法：①法術噴出（MGEF `archetype:"SpawnHazard"` + `association`，複用既有 MGEF wiring）②放置（`placements[].base` 是 HAZD 或 `kind:"hazard"`→`PlacedHazard`）。見 `SPEC-magic.md § hazards`、`CODE_MAP.items-magic.md`、`examples/hazard.json`。
- **Music (MUSC + MUST)**（2026-06-13，offline 完整、未實機）：`musicTracks[]`（MUST：SingleTrack→`.xwm`／Palette→子軌池／SilentTrack + loop）+ `music[]`（MUSC：flags/priority/`duckingDecibel`(正 dB 0–655)/tracks）。掛 `cells[].music` + `worldspaces[].music`（後者沿用既有 wire）。音檔 loose asset 走 `assets`。見 `SPEC-world.md § music`、`CODE_MAP.items-magic.md`、`examples/music.json`。**踩坑**：`duckingDecibel` 負值記憶體 OK 但 CLI build 寫檔 range-check（0–655）會炸。
- **互動式 perk（B組 #1，2026-06-17，offline + byte 待驗）**：`PerkEffectSpec` 兩個新 kind——`addActivateChoice`（`PerkEntryPointAddActivateChoice`：EntryType.Activate + ButtonLabel「[E] 標籤」+ 可選 Spell + conditions + `fragmentBody`）與 `setText`（`PerkEntryPointSetText`：Text 改活化提示），Immersive Interactions 那類。**Perk fragment dispatcher**：有 fragmentBody 的 choice → `Generator.PerkFragments.cs` 生 `<perk>_Frags extends Perk`、`Fragment_<i>(ObjectReference akTargetRef, Actor akActor)` 含 body；`AttachPerkFragments` 掛 `PerkAdapter` VMAD（`ScriptFragments.IndexedScriptFragment` 綁 + choice `Flags=RunImmediately|FragmentIndex`），gated on `.pex`（package 路徑，仿 quest/dialogue fragment；無 .pex 則 choice 仍建但 fragment 不掛＝spell-only/inert）。`EntryPointTabCount` 補 `Activate`=2（防 [[perk-conditiontabcount-ctd]]）。Mutagen shape 反射驗證（AddActivateChoice/SetText/PerkAdapter/IndexedScriptFragment/PerkScriptFlag）。**9 測綠**（record emit / fragment source / PerkAdapter VMAD 綁定[fake .pex] / 無 .pex 不掛 / validate）。example `interactive_perk_spec.json`。⚠ record-only（addActivateChoice+spell、setText）離線完全可驗；**PerkAdapter byte 欄 + Activate fragment 簽名待主力機 xEdit 比對真 IInteractions perk**（WAIT_USER）。玩家 perk 需 script AddPerk。
- **capturedItems[] 消費（擷取器①，2026-07-11，offline 完整＋DLL 真 json 端到端）**：`sc cap` 匯出的 `capturedItems[]` → `ExpandCapturedItems` 展開成 WEAP/ARMO(+新鑄 ENCH)/ALCH/INGR。附魔二選一：durable `enchantment.base`（撿到的既附魔物）直接引用；否則（玩家自附魔＝runtime ENCH 無 durable id）從 captured MGEF effects 新鑄 in-spec ENCH。editorId `MFCap_<name>_<i>`。`CapturedItemsTests.cs` 16 測（1 RequiresSkyrim 模板複製）。姊妹 capturedNpcs 見 [landed/npcs](npcs.md)。
