  - **🔑 base vs runtime 的分界（實機學到，計畫原本的前提只對一半）**：**外貌**（faceMorphs/headParts/hairColor/faceTexture/tintLayers/weight）確實寫在 **base TESNPC** 上（存檔會改寫它）→ 直讀即可。但**等級/血魔耐/18 技能**是 **runtime actor value**：`actor value = base + modifiers[permanent|temporary|damage]`，玩家的成長（升級加點、技能練級）堆在 **permanent modifier** 上，**base 永遠停在 chargen 起始表**。故一律讀 **`GetPermanentActorValue`**（＝base＋permanent，**不含**藥水/裝備附魔/受傷）——對沒有 permanent modifier 的 NPC，它與 base 讀起來相同 ⇒ 零回歸。⚠️ **白紙角色驗不出這個差別**（兩種讀法吐一樣的數字），必須用練過的角色驗。
