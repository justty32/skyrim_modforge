# mod-survey 缺口 — 💰 經濟 / 商販 / 服務 / 互動缺口

← [mod-survey-gaps](../mod-survey-gaps.md)

（mod 調查 2026-06-25，使用者指定；缺口已對 `src/` 驗證）

接 vendor + `settlements:` 落地後查的一批商販/服務/房產/NPC mod。詳見 [trade-and-barter](../../../../../analysis/mod-survey/findings/trade-and-barter.md) · [honed-metal](../../../../../analysis/mod-survey/findings/honed-metal.md) · [real-estate](../../../../../analysis/mod-survey/findings/real-estate.md) · [epw4npcs](../../../../../analysis/mod-survey/findings/epw4npcs.md) · [dynamic-animation-casting](../../../../../analysis/mod-survey/action-system/findings/dynamic-animation-casting.md)。

1. ❌ **GMST / game-setting 編輯（最乾淨的真缺口，來源 Trade & Barter）** — `src/` 證實**完全無 GMST 編輯能力**。Trade & Barter 是「一串條件化 `ModBuyPrices`/`ModSellPrices` EntryPoint perk（ModForge **已支援**，`Generator.Build.Perks.EntryPoints.cs` L31/L55）+ 一個 MCM 腳本」近乎純 perk overhaul——意味**條件化定價 perk + MCM 的經濟 tweak mod 今天就能生**，唯一缺的是調 `fBarterMin/Max`/`fSpeechcraftMin` 等之類的 GMST。建議加一個 `gameSettings:`/`gmst:` spec 區塊（純 record override，無 runtime、離線可驗、低風險），順手解鎖一大票「調平衡數值」型 mod。⚠ 待開 Trade & Barter 的 esp 用 Mutagen 確認它走 GMST vs VendorValues vs 純 perk+GLOB（agent 因 Nexus 403 無法 byte-inspect）。
2. 🟡 **`services:` macro（中價值，來源 Honed Metal；`settlements:` 的姊妹）** — 把 NPC tag 進服務 faction + 自動接條件對話開一個服務（鐵匠/附魔/訓練/代工）。scaffolding（faction + 條件服務對話 + MCM + FormList 能力清單 + 扣金幣 fragment + storage）**全在現有能力域**。**但 Honed Metal 核心是 bespoke runtime**：「開容器→腳本開原生製作選單」要 SKSE C++ DLL（ModForge 產不出，須附帶預建 asset），成本數學/perk-技能 gate 要手寫 Papyrus controller。⇒ macro 只生外殼、controller 走「附帶預寫 .pex/.dll 庫」路線。
3. 📌 **「付錢→給/改物件」交易 fragment pattern（非缺口，是可生成 macro 候選）** — 通用模板 `Player.GetGoldAmount() ≥ cost → RemoveItem(Gold) → 給/強化/附魔目標`。可重用於 vendor / 服務 / 賄賂 / 代工。乾淨、純 Papyrus fragment、離線可驗。
4. 📌 **能力清單即 FormList、由分發擴充（非缺口，是 idiom）** — Honed Metal「兩個 FormList（常見/稀有材料）+ FLM/CCOR patch 擴充」是 ModForge 已有記錄（FormList + FLM 分發）的乾淨 pattern，值得寫成 spec idiom 文件。
5. 📌 **MCM 切換 → GLOB → perk/condition 接線（待補一例）** — 「ship 一個 MCM」與「ship 一個可調機制 mod」的差別＝MCM 控件寫進 GLOB、條件/perk 讀該 GLOB。ModForge MCM + GLOB + CTDA 零件都有，缺一個把三者串起來的 worked example（Trade & Barter 是現成藍本）。
6. ✅ **`MessageSpec` 多按鈕選單（2026-08-11 offline 落地）** — `messages[].buttons[]` 寫 MESG ITXT，有序對應 Papyrus `Message.Show()` zero-based return；0 顆仍是 notification，validate 擋空 label / 超過 10 顆。record 層已收，calling fragment 的 `Show()` + branch 仍由各 macro/作者負責；這已解除 Real Estate / services / settlements Phase-2 `manageMenu:` 的共同 record 前置。
7. 🟡 **`settlements:` 的 `ownership:` / `income:` 維度（idea #22 收益面，來源 Real Estate）** — 現 `settlements:` 涵蓋住民/作息/店家 faction，缺「買下這棟→被動收益」那半。Real Estate 是最乾淨藍本：腳本化 Property Sign Activator（`Owned`/`Not owned` state machine）+ 計價 GLOB 組 + `RegisterForUpdateGameTime` 被動收租 + `SetActorOwner`/XOWN 所有權 + 可選 perk gate。**所有 primitive（GLOB/QUST/ACTI script-attach/XOWN `OwnershipSpec`/PERK/收租 fragment）已 landed**，缺的是把它們收成一個 ownership macro（且依賴 #6 的多按鈕選單做買/賣 UI）。
8. 🟢 **`animCasts:` / `dynamicAnimationCasting:` TOML loose-config（乾淨候選，來源 DAC NG Plus，屬 action-system 鏈）** — 已對 `src/` 驗證：無 DAC 支援、無 TOML emitter，但 `OarConditions.ParseForm` 已解 DAC 同款 `"Plugin.esp|0xHEX"` FormRef，`OarGen`/`BdiGen`/`SpidGen` 證 loose-config 生成成熟。只缺一個小 TOML emitter。emit `SKSE/plugins/_DynamicAnimationCasting/<mod>.toml`（`[[event]]` AnimationEvent→SpellFormIDs + 條件/屬性），重用既有 FormRef 管線 + 同 spec 的 `magic:` SPEL。補完 action-system 鏈「BDI→PIE→OAR→**施法輸出**」最後一段；DLL 屬玩家前置（同 BDI/PIE）。
9. 📌 **「global NPC perk/ability via SPID」recipe（非缺口，來源 EPW4NPCs）** — EPW4NPCs 整包＝2 行 SPID 把 vanilla EntryPoint perk 廣播給 `ActorTypeNPC`（`Perk|ActorTypeNPC`），ModForge `SpidGen` 已可 byte 等價生成（已驗證）。值得寫成 spec idiom：用 SPID 對「全 NPC / 某 faction / 某 keyword」無 patch 注入 perk/ability——對 vendor/settlements 的全人口注入直接可用。（真正不可生成的喝藥 AI 是姊妹 mod NPCsUsePotions 的 native DLL controller，同 SCAR 類限制。）
10. 📌 **「交易追蹤 controller」＝scaffold + 附帶 .psc（非缺口，是 pattern；來源 Supply and Demand）** — S&D 是**動態供需**（≠ Trade & Barter 靜態 perk）：cloak spell bootstrap 一個玩家 controller script，用 `OnItemAdded/Removed`+`Get/SetGoldValue` 追交易量、隨時間回價。**record 外殼全可生成**（GLOB/script-archetype MGEF·SPEL/CELL·CONT override/MCM），且 `ScriptAttachSpec.Source`（`Spec.Dialogue.cs:231`）能把作者手寫 `.psc` 編進 VMAD → **ModForge＝packager，動態演算法須手寫**。確認 #1 GMST 缺口仍在（但 S&D 不需 GMST）。Action：把 `ScriptAttachSpec.Source` 端到端驗一次 + 加 example。
