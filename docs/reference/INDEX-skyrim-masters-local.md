# Skyrim Masters Local Reference Map

This is the navigation map for local Skyrim master reference artifacts. Start here before running
`ls`, `find`, or broad repo searches.

## Quick Start For Agents

Use this directory first:

```text
/home/lorkhan/repo/ModForge/reference/skyrim-masters-local/
```

It contains the combined reference probes for:

- `Skyrim.esm`
- `Dawnguard.esm`
- `HearthFires.esm`
- `Dragonborn.esm`

If you only need split runs:

- `reference/skyrim-esm-local/` - Skyrim.esm only.
- `reference/skyrim-dlc-local/` - DLC masters only.

Do not treat these files as a full dump. They are a curated lookup cache plus a manifest and status
log. For records not already listed in `find/*.txt`, run the CLI `find` command directly against the
real master file.

## What To Open First

- Need proof the cache is valid: open `manifest.json`, then `run-status.tsv`.
- Need a known vanilla or DLC FormID: open `find/<Master>-<Type>-<query>.txt`.
- Need Story Manager root FormIDs: open `skyrim-smtree.txt`.
- Need to diagnose extraction failures: inspect non-empty files in `logs/*.err`.
- Need source master paths: use `manifest.json`; do not rediscover the Steam path.

## Voice Map

There are three different "voice" locations. Do not mix them up.

| Purpose | Location | Notes |
|---------|----------|-------|
| Vanilla voice archive | `$DATA/Skyrim - Voices_en0.bsa` | Contains packed vanilla `.fuz` under `Sound/Voice/Skyrim.esm/<VoiceType>/`. |
| Extracted reference clips | caller-chosen output, for example `reference/voice-clips/<VoiceType>/` | Not created by the master extraction. Create with `extract-voices`. |
| Generated mod voice lines | `<outModDir>/Sound/Voice/<plugin>/<voiceType>/` or next to built `.esp` | Created by `voicelines`; this is what Skyrim loads for new dialogue. |

Useful commands:

```bash
R="dotnet run --project src/ModForge.Cli --no-build --"
DATA="$HOME/.local/share/Steam/steamapps/common/Skyrim Special Edition/Data"

# List planned output folders/files without TTS.
$R voicelines examples/dialogue_spec.json Out/dialogue.esp --plan
$R voicediag examples/dialogue_spec.json Out/dialogue.esp

# Extract vanilla reference clips for one voice type.
$R extract-voices "$DATA/Skyrim - Voices_en0.bsa" FemaleYoungEager reference/voice-clips/FemaleYoungEager
```

Known in-game voice file layout:

```text
Sound/Voice/<plugin>/<voiceType>/<quest10>_<topic15>_<infoFormId8>_<responseIndex>.fuz
Sound/Voice/Skyrim.esm/<VoiceType>/*.fuz          # inside Skyrim - Voices_en0.bsa
```

## Find Cache Naming

Files in `find/` use this pattern:

```text
<MasterWithoutExtension>-<RecordType>-<query>.txt
```

Examples:

- `find/Skyrim-Race-nord.txt` - Nord race FormIDs from Skyrim.esm.
- `find/Skyrim-Cell-banneredmare.txt` - Bannered Mare cell lookup.
- `find/Dawnguard-Npc-serana.txt` - Serana lookup.
- `find/Dawnguard-Weapon-crossbow.txt` - Dawnguard crossbow records.
- `find/Dragonborn-Location-solstheim.txt` - Solstheim location lookup.

Current cached query set per master:

```text
Race:nord
Class:blacksmith
Keyword:armorclothing
MagicEffect:restorehealth
Cell:banneredmare
Worldspace:tamriel
Npc:serana
Weapon:crossbow
Book:spelltome
Location:solstheim
```

## Output Format

`find/*.txt` rows look like:

```text
Skyrim.esm:0x013746  Race  NordRace
Dawnguard.esm:0x002B6C  Npc  DLC1Serana
Dragonborn.esm:0x016E2A  Location  DLC2SolstheimLocation
```

Use the first column directly in JSON specs when the field accepts a ref:

```json
"race": "Skyrim.esm:0x013746"
```

For CLI diagnostics, pass only the numeric FormID argument:

```bash
R="dotnet run --project src/ModForge.Cli --no-build --"
SK="$HOME/.local/share/Steam/steamapps/common/Skyrim Special Edition/Data/Skyrim.esm"
$R npcdiag "$SK" 0x013746
```

Use the correct diagnostic command for the record type: `npcdiag`, `packagediag`, `weatherdiag`,
`questdiag`, `bookdiag`, `factdiag`, `scenediag`, and so on. Run
`dotnet run --project src/ModForge.Cli -- --help` for the full command list.

## Run Status Format

`run-status.tsv` columns:

```text
master	command	type	query	output	status	log
```

Expected healthy combined run:

```text
41 rows total
41 OK
0 FAIL
0 non-empty logs/*.err
```

The 41 rows are 40 `find` probes plus `smtree Skyrim.esm`.

## Rebuild Or Extend The Cache

From repo root:

```bash
cd /home/lorkhan/repo/ModForge
scripts/extract-skyrim-masters.sh
```

Override the Skyrim Data directory:

```bash
MODFORGE_SKYRIM_DATA="/path/to/Skyrim Special Edition/Data" \
scripts/extract-skyrim-masters.sh
```

Write to a different output folder:

```bash
MODFORGE_REFERENCE_OUT="/tmp/modforge-skyrim-reference" \
scripts/extract-skyrim-masters.sh
```

Run only selected masters:

```bash
MODFORGE_SKYRIM_MASTERS="Skyrim.esm" \
MODFORGE_REFERENCE_OUT="/home/lorkhan/repo/ModForge/reference/skyrim-esm-local" \
scripts/extract-skyrim-masters.sh
```

## When The Cache Is Not Enough

Use direct CLI lookup instead of scanning the repo:

```bash
R="dotnet run --project src/ModForge.Cli --no-build --"
DATA="$HOME/.local/share/Steam/steamapps/common/Skyrim Special Edition/Data"

$R find "$DATA/Skyrim.esm" "whiterun" Cell
$R find "$DATA/Dawnguard.esm" "crossbow" Weapon
$R find "$DATA/Dragonborn.esm" "solstheim" Location
```

Then use the returned FormID with a diagnostic command:

```bash
$R cellblk "$DATA/Skyrim.esm" 0x01605E
$R bookdiag "$DATA/Skyrim.esm" 0x09E2A7
$R weatherdiag "$DATA/Skyrim.esm" 0x10E1F2
```

## Agent Rules

- Start from this file, `manifest.json`, and `run-status.tsv`.
- Do not crawl `reference/` broadly unless this map says the target is not covered.
- Do not assume `find/*.txt` is exhaustive; it is only the scripted query set.
- Prefer `dotnet run --project src/ModForge.Cli --no-build -- find ...` for new vanilla lookups.
- Keep generated outputs under `reference/`; it is gitignored and machine-local.
