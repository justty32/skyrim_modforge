## How they relate to ModForge

Both Mutagen tools, both output `.esp`, both have a CLI — but orthogonal: **Synthesis PATCHES an
existing load order** (end-user conflict resolution), **ModForge GENERATES new content from a JSON
spec** (authoring). The most liftable idea from Synthesis is its settings model — a C# settings class
decorated with attributes yields JSON persistence + a discoverable schema for free, the closest
parallel to ModForge's spec approach.
