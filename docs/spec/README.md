# ModForge JSON spec manual

[`SPEC-index.md`](SPEC-index.md) is the entry point for every supported JSON field. It links to the topic pages for records, dialogue, quests, worldspaces, packages, animation, distribution, voice work, and references.

This folder documents the JSON contract that ModForge consumes. Design proposals belong in [`../../workflows/specs/`](../../workflows/specs/README.md); complete examples live in [`../../examples/`](../../examples/).
