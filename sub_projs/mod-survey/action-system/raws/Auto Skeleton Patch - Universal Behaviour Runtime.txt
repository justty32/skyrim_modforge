Using skeleton mods without a behaviour patch will cause weird blending issues, the worst offenders being:

Hand not moving while casting in motion
Not playing block animation while strafing
Wonky bow animations﻿
Freezing
CTD

This mod just patches the behaviour dynamically so that you never have to worry about behaviour patching when using skeleton mods. This also means that skeleton mods itself no longer need behaviour engine patching, they can just have this mod installed. 

TL;DR: Behavior patch for Skeleton mod like XPMSSE but written in SKSE and compatible WITH ANY Skeleton. You still need behaviour engines for other types of animation mods!
