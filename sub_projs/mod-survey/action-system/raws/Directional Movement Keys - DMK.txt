Directional Map (8-Way Movement) + No Movement

When creating or editing animations, the DirecionalCycleMoveset and
Graph Variable uses the following integer values to represent directions:

0 = No Movement
1 = Forward
2 = Forward-Right
3 = Right
4 = Backward-Right
5 = Backward
6 = Backward-Left
7 = Left
8 = Forward-Left
Directional Camera Map (8-Way) + Neutral

When creating or editing animations, the CameraMovementCMF
Graph Variable uses the following integer values to represent directions:

0 = No Movement
1 = Forward
2 = Forward-Right
3 = Right
4 = Backward-Right
5 = Backward
6 = Backward-Left
7 = Left
8 = Forward-Left

Extended Complex Directions (Keyboard Exclusive)

The following combinations represent complex inputs (simultaneous opposite keys or 3 keys at once).
Note: These are Keyboard Only. Gamepads physically cannot trigger these states. If your moveset or logic reaches a point where you need to rely on these complex 3-key combinations, it is highly recommended to design a 2nd layer (using a modifier key) instead of relying on these states.

Extended Action Keys (Dtry Extended)
These are evaluated using their respective Graph Variables Bool
(Comparing to Int == 1 for True).
Here is how you can access them via Keyboard and Gamepad (Controller):


DMKLeftShift
Keyboard: Left Shift
Gamepad: Right Stick Left

DMKLeftAlt
Keyboard: Left Alt
Gamepad: Right Stick Right

DMKQ
Keyboard: Q
Gamepad: Right Stick Down

DMKE
Keyboard: E
Gamepad: Right Stick Up

DMKZ
Keyboard: Z
Gamepad: (No Gamepad Mapping)

DMKX
Keyboard: X
Gamepad: (No Gamepad Mapping)
