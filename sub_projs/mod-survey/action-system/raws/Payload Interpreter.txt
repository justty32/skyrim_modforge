Before posting the bug, make sure that the mod is directly related to the occurance of the bug by:
1. make a save where the bug happens
2. disable the mod
3. launch the game
4. make sure the bug isn't happening anymore. If it still happens, the mod isn't the cause.
5. re-enable the mod
6. launch the game, load the same save
7. the bug comes back

Please provide adequate information for me to actually be able to help you! Report bugs in the following format:

Title:

brief description of your issue

Text:
Environment: mod manager you're using(MO2/Vertex/NMM); game version(AE/SE); operating system(windows7/8/9/10.../Linux/MacOS)
Details: what were you doing when the bug happens? what is happening in game? is there anything specific happening right before/after the bug happens?
Relevant info: what do you think could be relevant to the occuring of the bug?
Attempt to debug: what have you tried so far to resolve the bug? 
Crash log: if the game crashed and you doubt this mod is the culprit, provide a link to either a .net﻿ crashlog(SSE) or a crash logger﻿ log(AE). Don't directly paste your crashlog in text!
