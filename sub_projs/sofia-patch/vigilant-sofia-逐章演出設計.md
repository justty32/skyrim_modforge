## 0. 核心設計原則（最重要、貫穿全 patch）

### 0.1 角色定位與成長弧
- 玩家遇到 Sofia 時，她**已經是經驗豐富、有歷練的冒險者**——不是新手。
- 但 VIGILANT 的旅程**牽扯層級很高**（魔神、神話時代、Coldharbour…），所以 Sofia **仍然會有變化與成長**。
- **她本人會抗拒這種成長**：成長透過嘴砲/逞強/說溜嘴的縫隙滲出，不是直白的角色宣言。

### 0.2 夢境 / 回憶 / 單人場景：Sofia 以「幻影隨身掛件」在場 ★ 主要 patch 需求（2026-06-14 定案）
VIGILANT 大量使用「**玩家被拉入他人的夢**」「**玩家與特定人物的回憶**」「**單人場景**」。處理方式**不是把她拿掉**，而是：
- **Sofia 以思念體 / 幻影形式跟進**（不是肉身，也不是在外面等）。她像**玩家的隨身靈掛件**。
- **夢/回憶中的 NPC 一律把她當空氣**——看不見她、不與她互動、不對她 forced-greet，她也**不參與該 scene**。所以她**完全不介入、不破壞劇情**。
- 她**只與玩家互動**：對眼前劇情吐槽、發表看法、對**玩家的動作與選擇**做反應。可主動 ambient，也可玩家可問。
- 進場瞬間她會**對「換地方」表示驚訝**（她跟玩家一樣是被動被牽扯進來的）。

> 對比舊定調：`vigilant-support-plan` 講「在哪加可問選項」；這條講「夢/回憶場景裡她**在場但隱形**，只跟玩家講話」。技術預期：偵測這類 scene/cell 進入時，gate 掉她與劇情 NPC 的任何互動（no scene participation / no forced greet / 不被 NPC 偵測），只保留她對玩家的 ambient + player topic。實作手法待設計，但行為規格已明確。

**跟不跟入 = 逐場決定（2026-06-14 補）**：不是每個夢都跟入。
- **跟入（幻影掛件）**：劇情關鍵、有 Sofia 值得反應的料的夢——例：第二章 Lamae 夢、第四章的 **Pelinal**、**Molag Bal**。
- **不跟入**：其餘大量記憶（**第四章冷港大部分**）——她留在外圍，不進該記憶，那段不產生她的對話（最多留「出來後玩家可問」的輕量選項）。避免她在每一段悲劇記憶都插嘴而稀釋情緒。

### 0.3 跟隨的合理性 = 命運的糾纏 ★ RESOLVED（2026-06-14 使用者定案，原 OPEN 已解）
- 為什麼一個凡人冒險者進得了夢/魔神層級的地方？→ **命運的糾纏**：因 Sofia 與玩家**糾纏極深**，當玩家被拉入夢，她以**思念體 / 幻影**的方式被**一併牽扯進來**。
- 關鍵：她**不是真的在那個位面**，而是玩家羈絆/意識的延伸。這正好自洽解釋了 §0.2 為何夢中人看不到她（她不真的「在」），以及她為何只能跟玩家互動。
- 包裝語氣「高大上」即可（命運、糾纏、思念所繫），但本質是 gameplay 上的「隱形隨身掛件」。

### 0.4 高位格存在（Molag Bal）特例 ★ 2026-06-14
- **Molag Bal 這種高位格存在能看到 Sofia**（凡俗夢境 NPC 看不到，但魔神看得到）。
- 但他**把她當空氣 / 當作玩家的替代品**——因為只有**玩家（Dragonborn）**才值得他正眼相待。
- **Sofia 面對這種真正超越她層級的存在**：這是角色弧的**高張力點**——她一貫的嘴砲/逞強，在一個真能碾碎她的東西面前還撐不撐得住？`(?)` 具體反應待寫（可朝「嘴砲音量變小、第一次認真害怕又死不承認」發揮）。

## 1. 第一章（Act 1）：加入 Vigilant → Stendarr 信標屠殺 → 女巫抉擇

### 1.1 加入組織 / 身份建立
- 玩家加入 Vigilant 組織、四處出任務。此階段 **Sofia 確實能跟過來**。
- 可給她**安排身份**：和玩家一起加入 Vigilant。
- 學習**治療法術、驅散不死（turn undead）之類**的法術（呼應她在這條線上的成長）。

### 1.2 前期任務（一般）
- 第一章前幾個任務沒有特殊處理：**Sofia 跟著**，**任務結束後發表感想**。

### 1.3 貓人（Khajiit）任務 — Jovanni 的夢 ★ 排除點
- 此任務玩家會**進入 Jovanni 的夢**。
- **Sofia 不該進入這個夢**（套用 §0.2）。
- **從夢中出來後**，Sofia 才**詢問玩家剛剛發生了什麼**。
- `(對應待核對：act-1-sq-06-kahjiit)`

### 1.4 第一章末：回 Stendarr 信標 = 全體 Vigilant 被殺 ★ 嚴肅場面（第一個大重點）
- 玩家回到 Stendarr 信標，發現**所有 Vigilant 都被殺死**。
- 這是**第一個大重點 / 嚴肅場面**——Sofia 的反應要對得起這個基調（不是純嘴砲）。
- 進入信標**地下** → **第一章末尾 boss 戰**。
- 這段劇情後，**Sofia 會有感觸**。

### 1.5 Artano 的女巫任務 — 道德質疑 ★ 玩家抉擇 + Sofia 表態
- Artano 要玩家去**殺死某地的女巫**。
- **Sofia 提出質疑**：認為**這兩個不像是女巫**。
- 依**玩家的選擇**（殺 / 不殺女巫）：Sofia **有自己的看法，但仍支持玩家的決定**。
- 回到 Stendarr 信標：**Sofia 覺得 Artano 怪怪的**。
- 接著 **boss 戰**：**Carene 跑進來**，玩家可選**殺或不殺**，**Sofia 支持玩家的決定**。
- `(對應待核對：act-1-sq-sub-01-witch 等)`

### 1.6 回報任務 / 章節收束
- 回 Stendarr 信標回報任務：**Sofia 說「可以休息一會了」**。

## 2. 第二章（Act 2）：Windhelm 地下 → Lamae

### 2.1 開章
- **Windhelm 衛兵過來**，開啟第二章：**Sofia 說「好吧，又有事情要忙了」**。

### 2.2 讀書推進度 → Sofia 的學識面
- 玩家**讀某本書**推進任務進度後，**Sofia 也會有反應**：說她**以前看過相關的書**，然後**發表看法**（呼應她有歷練/有讀過東西的一面）。

### 2.3 進入 Windhelm / 下水道
- 進入 Windhelm，**進入下水道前**：Sofia 發表看法。
- **下水道內**：Sofia **抱怨這地方**，還有**吸血鬼**。
- 面對搜查隊的一些**有名人物**時：Sofia **可能也能發表看法**。

### 2.4 Lamae 沉睡的宮殿
- 在 **Lamae 沉睡的宮殿**裡：Sofia 也會發表看法。

### 2.5 與 Lamae 交互 → 切換地圖 → 進入「吟遊詩人與 Lamae 的夢」★ 幻影跟入（§0.2/§0.3 的第一個實例）
- 玩家與 Lamae 交互後**切換地圖**：**Sofia 驚訝「怎麼突然換地方了」**（§0.2 進場驚訝）。
- 此地其實是**吟遊詩人與 Lamae 的夢**。Sofia 以**思念體/幻影**被命運糾纏牽入（§0.3），成為玩家的隨身掛件；**夢中人物一律把她當空氣**（§0.2）。

### 2.6 夢中演出 — Sofia 的學識面 + 即時反應
- Sofia **因看過相關書籍**（呼應 §2.2 讀書 beat）對夢中情節**有反應、有自己的看法**。
- 也會**對玩家的動作與選擇做反應**（玩家可問為主，關鍵處可主動吐槽）。
- 夢中若出現 **Molag Bal**：套 §0.4（他看得到她、但當她空氣/玩家替代品；她面對高位格的反應）。

### 2.7 雙重 Lamae 戰 + 王座提示
- 打完 Lamae、**離開夢之後，要再打一次 Lamae**：Sofia **吐槽「怎麼 Lamae 打不死」**，然後**提示玩家「王座上有東西」**（gameplay 提示）。

### 2.8 章節收束
- 打完後 Sofia 覺得**「這真是一次驚險的任務」**。

## 3. 第三章（Act 3）：可怕的宅邸（Mansion Mystery）

> 對應 reconstruction：`act-3-sq-01-child` 等。基調＝恐怖。**本章 Sofia 定調特殊：為掩飾恐懼而不斷插科打諢，以「主動評論」為主**（與前面「玩家可問為主」不同——恐怖氛圍下她話特別多，靠嘴砲壓住怕）。
> **幕結構釐清**：寒港（Coldharbour）的 13 段記憶**是第四章**，在本章末「進入冷港」之後才開始（見 §3.8）。

### 3.1 宅邸基調：主動插科打諢掩飾恐懼 ★
- 第三章是很可怕的宅邸。Sofia **為了掩飾恐懼會吐槽**。
- **盡可能讓 Sofia 不斷插科打諢、且是主動評論**（【在場·環境吐槽】拉到最滿；本 patch 裡她主動話最多的一章）。

### 3.2 讀文本 → 評論
- 玩家讀某些文本時，Sofia 也應能發表評論。

### 3.3 觸碰塑像 / 進地圖打怪 → 跟隨 + 感想
- 玩家觸碰一些塑像、進入一些地圖打怪時，Sofia 跟著並發表感想。

### 3.4 紅女巫（雜兵）→ 邊吐槽邊打
- 宅邸中出現「紅女巫」這種敵人：Sofia 發表感想，一邊吐槽一邊打架。

### 3.5 紅魔女（大 boss）→ 感想
- 最後大 boss「紅魔女」，Sofia 也要發表感想。

### 3.6 管家 Baal（其實是吟遊詩人）→ Sofia 生氣 ★
- 面對管家 Baal——這傢伙就是（第二章夢裡的）吟遊詩人——**Sofia 會生氣**（呼應前面的恩怨）。

### 3.7 Julius（尤里烏斯）火焰 boss ★
- 最後的 Julius boss 讓場地充滿火焰。
- Sofia **奮起，喊「松加得（Tsun）」之類的話**（戰吼/求神）。

### 3.8 火焰未熄 → 抉擇：被燒死 or 進入冷港 ★★ 關鍵分歧
- 打完 Julius 後火焰沒熄滅，玩家陷入兩個抉擇：**被燒死** 或 **進入冷港（Coldharbour）**。
- Sofia 支持玩家的抉擇：
  - **進入冷港**：Sofia 跟著進去。
  - **被燒死**：Sofia 高喊「松加得」之類，跟玩家一起掛掉 → 然後跟著玩家傳送回冷港 → Sofia 驚訝「自己不是被燒死了嗎」→ 疑惑一陣後想「可能是九聖靈吧…」**輕輕帶過（不著墨太多）**。

### 3.9 ★ Meta 轉折（VIGILANT 的核心詭計，牽動 Sofia 的連續性）
- **若玩家選擇被燒死**：其實第一～三章**不是龍裔玩家完成的，而是另一個警戒者**。
  - 燒死後玩家回斯坦達爾聖堂**重新捏臉**＝換成第二個人（龍裔）。
  - 回到宅邸可看到一個**焦屍**＝前一個警戒者（被燒死的那個）。
  - 新玩家只是隨便晃蕩過來的龍裔。
- **進入冷港的，一定是龍裔。**
- **對 Sofia patch 的影響**：若走「燒死→換龍裔」線，Sofia 在冷港重新出現的連續性，用 §0.3 命運糾纏 +「九聖靈」一語帶過（§3.8）。**不深究、保持輕巧。**

## 4. 第四章（Act 4）：冷港（Coldharbour）

> 基調**比前面舒適/輕鬆**（脫離宅邸恐怖後的喘息），Sofia 回到她舒服的嘴砲節奏。對應 reconstruction：`act-4-memory-*`（13 段記憶，已全 PSC 解碼）。

### 4.1 記憶夢境：大部分不跟入 ★（套 §0.2「逐場決定」）
- **大部分記憶夢境 Sofia 不用跟進去**（留在冷港外圍）。
- **少數例外要跟入**（幻影掛件）：**Pelinal**（MeQ10–12 Song of Pelinal）、**Molag Bal** 相關（§0.4 高位格特例）。
- 其餘記憶不產生她的在場對話（避免每段悲劇都被插嘴稀釋）；要的話僅留「出來後玩家可問」的輕量選項。**哪幾段跟、哪幾段不跟，逐段清單待你定。**

### 4.2 地點感想
- 冷港的一些地點，Sofia 也需要能發表感想（【在場·環境吐槽/玩家可問】；realm 素材見 [`vigilant-support-plan-2026-06-13.md`](vigilant-support-plan-2026-06-13.md) §1 的 11 realm 表）。

### 4.3 Molag Bal / 結局
- Molag Bal 場景套 §0.4（他看得到她、當她空氣/玩家替代品；她面對高位格的角色弧高張力）。
- Karma 多重結局：Sofia 在不同結局的反應 `(?)` 待續講。
