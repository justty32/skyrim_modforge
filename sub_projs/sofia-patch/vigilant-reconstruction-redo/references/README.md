# VIGILANT secondary references

這個資料夾只放二級參考：玩家解析、影片逐字稿、社群文章整理。

使用規則：

- 不把這裡的說法當作 canonical source。
- 重做劇情整理時，只把這裡當成「要去 ESM / extracted game data 驗證的線索索引」。
- 真正可引用的原文仍以 `../../game-data/mods/Vigilant/` 與 `Vigilant.esm` 診斷輸出為準。
- 若二級參考與 ESM / extracted text 衝突，採 ESM / extracted text。

## Files

- `zhihu-vigilant-review-notes.md` - 使用者提供的知乎文章與留言整理。
- `video-transcript-notes.md` - 三份影片逐字稿的合併整理與待驗證路線圖。
- `someone's video.txt` - 原始影片逐字稿；偏實況流程與個人體驗。
- `another video.txt` - 原始影片逐字稿；結構較清楚，Act IV / endings / story explained 很有用。
- `yet another.txt` - 原始影片逐字稿；包含較多口語 lore 解釋、Orlando skip、Dragon Break / ending interpretation。
