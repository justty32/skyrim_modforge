## 原始輸出

Research into the Skyrim modding community confirms that while **Custom Skills Framework (CSF)** is primarily designed for player-character progression, several mods and frameworks allow you to manage NPC and follower perk trees through various user interfaces (UIs), including some that mimic or utilize the star constellation system.

### 1. Mods for Managing NPC Perk Trees via UI

| Mod Name | Nexus ID | Description | URL |
| :--- | :--- | :--- | :--- |
| **Follower Perk and Spell Manager (FPSM)** | 46820 | Allows you to teach followers spells and assign them perks via a list-based UI (using UIExtensions). Often cited as the most direct management tool. | https://www.nexusmods.com/skyrimspecialedition/mods/46820 |
| **NPC Perk Tree Management** | 122240 | A utility by Dylbill that adds a system to manage and assign perks to any NPC. It uses a custom menu system to customize follower combat styles. | https://www.nexusmods.com/skyrimspecialedition/mods/122240 |
| **Proteus (formerly Project Proteus)** | 62985 | **Closest to request.** Allows "swapping" control to an NPC/follower. Once controlling them, you can open the standard **star constellation UI** to spend perk points as if they were the player character. | https://www.nexusmods.com/skyrimspecialedition/mods/62985 |
| **Skyrim Party Sheet** | 111836 | Provides a dedicated "Party Sheet" UI (F6) that displays detailed follower stats, including their active perks and skill levels. | https://www.nexusmods.com/skyrimspecialedition/mods/111836 |

### 2. CSF & NPC Context

- **Custom Skills Menu - A Unified Menu** (ID: 65982): Adds a "Custom Skills" tab to the player's Tween Menu (TAB menu) to browse all installed CSF trees.
- **Constellations - A True RPG (Modlist/Collection)**: A massive modlist by IxionXVII. Uses CSF for player trees + Party Sheet to make NPC perks visible.
- **Be a Leader - Custom Skills Framework** (ID: 53051): Gives the *player* a CSF "Leadership" constellation. Perks taken directly modify/manage follower capabilities.

### 3. Auto-scaling approaches (no UI management)

- **Scaling Perks for NPCs** (ID: 94350): SPID-based auto perk assignment as NPCs level up.
- **NPCs Learn Skills and Spells** (ID: 76491): SPID-based NPC progression from installed perk overhauls.
- **More Informative Console** (ID: 19250): Console sidebar shows all NPC active perks/effects.

### Summary (Gemini's)

> For visual "star constellation" experience for NPCs → **Proteus** (swap & edit).  
> For dedicated management menu without swapping → **FPSM**.
