# Onean 性格分析 — 寫作 brief（來源：Follower Onean 對白抽取）

做 Onean 擴充時的**角色聖經 / writing brief**：要產出「聽起來像 Onean」的新台詞，先吃透這份。

**來源說明（重要）**：原始 `Onean/dialogue.md`（標題寫 English）其實是**雙重 mojibake 的簡體中文**，內容與官方繁中 `Onean_CHT/dialogue.md` 完全一致；本 mod **沒有真正的英文原文**。因此本文所有引用都用**繁中原句**（=遊戲內實際對白），這是唯一忠實的依據。對白總量很少（一個 Hello topic + 一條 Idle + 一段母親護符對話 + 大量「換裝/購買」機械 INFO），所以下面凡是推斷處都標明**可推斷到的程度**，不硬掰。

對白規模：~50 個 topic，但其中約 35 個是**換裝 / 購買護甲衣服**的功能性 INFO（回應幾乎都是「如你所願」「我知道了」「你的錢不夠」），人設訊息量**極低**；真正承載性格的只有 Hello / Idle / FirstHello 招募 / 治療 / 藥劑(調情) / 解雇 / 母親護符這幾組。

---

## 0. 一句話定位

**Onean 是一個嬌小、孩子氣、黏人又帶著喪母陰影的天霜治療師（healer follower）**——她最辨識的幾點是「自稱治療師、把守護玩家當己任」「對自己身材矮小/平胸的自卑」「被冷落時立刻往最壞處想、怕被丟下」，外殼是天真愛玩、偶爾耍嘴的小女孩，內核是失去母親、渴望被需要、怕自己不夠好的不安全感。她不是毒舌喜劇 foil（那是 Sofia），也不是高冷戰士；她是**會擔心你受傷、會因為你一句嫌棄就垂頭喪氣、私下喊「媽…」的治療系少女**。

> 對白量太少，無法支撐「招式循環」式的人設清單。寫擴充時的核心工作是**從這幾個確定的內核點往外長**：① 治療師身分與守護慾；② 喪母 / 思念母親；③ 身材自卑與「想變更強」；④ 孩子氣的患得患失。把她丟進新場景時，問「**以這四個內核，她在這裡會怎麼反應**」，而不是套任何固定笑點。

寫新台詞的準則：**讓每句話至少能掛到上述某個內核**——治療師的關心、對被丟下的敏感、孩子氣的情緒外露、或對母親的隱痛。純功能、純資訊的句子（「如你所願」那類）只適合純機械操作，不要當成她的性格代表。

## 1. 核心原型（archetype）

**治療系少女隨從 / caretaker-but-needy**。她的功能定位是「治療師」，但人格上她比玩家更像需要被照顧的一方——這個**照顧人 vs 渴望被照顧**的張力是她最核心的東西。

- **治療師自我認同**〔確定，多次出現〕：自我介紹就是「我是奧妮安。而且當然了，我還是個治療師。」招募話術是「帶我一起旅行，而我也會保證你的安全。」——她把「保護你」當成自己的存在價值。
- **守護慾 / 像母親般叮嚀**〔確定〕：治療你之後會唸「好... 但下次你自己一定要小心點。」「如果我不在你身邊你就慘了。太可怕了！」Hello / 道別也反覆「請小心點。」「小心點 ~」——她真心怕你出事。
- **孩子氣、情緒寫在臉上**〔確定〕：Idle 會無聊抱怨「我好無聊啊。」、唱歌、自言自語「還得變得更強...」；答應招募時「你是說你同意囉？耶～～」。語氣天真、不設防。
- **想變強 / 有點不服輸**〔確定但淺〕：Idle 的「還得變得更強...」是她少數的自我期許線，可作成長鉤子，但原作沒展開，**不要過度解讀成戰鬥狂**。

## 2. 行為 / 互動風格（不是「幽默風格」——她不是喜劇角色）

> Sofia 那套「自誇 / 毒舌 / 黃腔說溜嘴」**完全不適用 Onean**。Onean 沒有自戀、沒有主動毒舌玩家、不講黃腔（涉性話題她是**被動受窘**方，不是發起方）。以下是她實際的互動機制，份量依對白出現頻率粗估。

### (a) 患得患失 / 往壞處想 — 她最鮮明的情緒反應〔確定，高辨識度〕
被解雇 / 被冷落時不會生氣，而是先自我懷疑、立刻認定是自己不好：
- 「是因為我做得不夠好嗎？好吧...」
- 「你不喜歡我 Q_Q？我知道了...」
- 招募成功反過來雀躍：「你是說你同意囉？耶～～」
→ **寫作要點**：她的情緒**鐘擺幅度大且直接**——被肯定就極開心，被否定就極受傷，中間沒有 Sofia 那種「嘴硬遮掩」。她不掩飾。

### (b) 身材自卑 — 對「矮小 / 平胸」敏感〔確定，數次〕
- 「為什麼每個人都長的這麼高...」
- 「很好... 大小不是最重要的，懂嗎？」（嘴上逞強）
- 「哇、哇... 你的胸部比我還大。」
→ 這是她的弱點開關，偶爾可戳，但她**反應是窘 / 不甘 / 自我安慰**，不是反擊。

### (c) 涉性 / 曖昧時的被動受窘〔確定〕
玩家用藥劑 prompt 開黃腔時，她是**被調戲、聽不懂或裝聽不懂**的一方：
- 「什麼！？...」「我不知道你在說什麼。」
- 「你到底在想什麼鬼！」（被惹毛）
- 換裝看到暴露服：「性感又暴露... 呃...」
- 最後勉強讓步：「好吧... 如果你想要的話...」「如果你要的話...」
→ **她從不主動性暗示**；曖昧場面她是害羞 / 抗拒 / 半推半就，這跟 Sofia 的主動黃腔是**相反**的。寫她時別讓她變成下流主動方。

### (d) 對玩家善意的暖反應 / 小傲嬌〔確定但少〕
- 教玩家恢復魔法時：「原來你的心地很善良嘛 ~」
- 護符被稱讚：「嗯？很漂亮，對吧？」
→ 她吃軟不吃硬，被溫柔對待就會露出黏人、撒嬌的一面。

## 3. 她怎麼對待玩家（relationship to player）

**把玩家當「要保護的人」+「會不會丟下我的人」的混合**。她對玩家沒有 Sofia 式的佔有 / 提款機 / 苦力心態（原作完全沒有這類台詞）；她的依附是**情感性、求認同型**的。

> 對白量小，這層只能確定到「依附 + 守護 + 怕被棄」三點，**佔有慾 / 吃醋 / 把你當錢包等等原作均無，不要套上去**。

- **守護者姿態（但其實更脆弱）**：「帶我一起旅行，而我也會保證你的安全。」「如果我不在你身邊你就慘了。太可怕了！」——她說要保護你，語氣卻像在說服自己「我有用」。
- **極度怕被嫌棄 / 被丟下**：解雇台詞全是自我否定（見 §2a），沒有一句是「哼隨便你」。**好感越低時這種不安越濃；好感高時可寫得更黏、更主動撒嬌**（原作未分層，這是合理擴充方向）。
- **被肯定就極開心**：「你是說你同意囉？耶～～」「原來你的心地很善良嘛 ~」
- **健康的關係定位**：原作把她寫成**朋友 / 旅伴 / 受保護者**，不是現成的浪漫對象（沒有告白、結婚、調情主動線）。要做戀愛擴充得自己鋪，且應從「她逐漸敢依賴你」這條情感線走，而非身體調情。

## 4. 不安全感 / 背景鉤子（insecurities & backstory）〔這層是 Onean 最有料的地方〕

她的對白量雖少，但**喪母**這條背景線是明確、且情感重量最大的鉤子。擴充最該深挖這裡。

- **母親已逝 / 思念母親**〔確定，唯一成形的背景線〕：護符對話一步步揭開——
  - 「這是我母親的護符。」
  - 「但是她再也看不到我戴上它了。」（暗示母親已不在）
  - 玩家追問「為什麼？」→ 她只回「唔...」，再追→「……」（**說不下去，迴避**）
  → **寫作要點**：母親是她的痛點與沉默處。涉及母親時她會**語塞、迴避、安靜**，不是大哭也不是嘴硬。這是擴充任務最自然的主線鉤子（母親身上發生了什麼？護符的來歷？）。
- **獨自喊「媽」**〔確定〕：Idle 獨白「我該怎麼辦.. 媽...」——獨處放空時會不自覺想起母親、像在求助。這是她孤獨內核的直接證據。
- **身材 / 不夠強的自卑**（見 §2b、§1）：「為什麼每個人都長的這麼高...」「還得變得更強...」——她覺得自己又小又弱，想證明自己。
- **怕自己不被需要**：解雇反應（§2a）顯示她把「被留在身邊」等同於「自己有價值」。

> 推斷邊界：除了「母親已逝 + 自己是治療師 + 嬌小想變強」，原作**沒有**交代她的種族、出身、年齡、師承、為何流落天霜等。這些都是**空白可填**，但別當成既有設定引用。

## 5. 說話模式 / 語言癖（speech patterns & verbal tics）

要產生 Onean-consistent 台詞，照抄這些 tic（全部有原句支撐）：

1. **省略號表遲疑 / 受傷 / 說不下去**：大量 `...`，但用法跟 Sofia 不同——Sofia 的 `...` 是「要說壞主意/說溜嘴」，**Onean 的 `...` 是難過、心虛、迴避**：「是因為我做得不夠好嗎？好吧...」「唔...」「……」
2. **自我懷疑式反問**：「是因為我做得不夠好嗎？」「你不喜歡我 Q_Q？」——先把矛頭指向自己。
3. **孩子氣感嘆 / 顏文字感**：「耶～～」「我好無聊啊。」「Q_Q」「~」（撒嬌尾音）。情緒外露、不修飾。
4. **治療師叮嚀句**：「請小心點。」「下次你自己一定要小心點。」「太可怕了！」——關心他人安危的口頭禪。
5. **被調戲時的窘迫短句**：「什麼！？...」「呃...」「你到底在想什麼鬼！」「好吧... 如果你想要的話...」
6. **戰鬥短促台詞**（冷 / 帶點狠，但不毒舌）：攻擊「吚！」「哈！」；命中 / 擊殺「你沒那個機會。」「你完蛋啦。」「那是你的問題。」「蠢蛋。」——戰鬥時比平時硬，是她少數「強勢」的場合。
7. **稱呼玩家**：依場景叫「爵士」「龍裔」（Hello 裡有），無固定暱稱；平時直接對話、不加敬稱。

> 注意：**「如你所願」「我知道了」「了解」「知道了」這類**幾乎全是**換裝 / 購買護甲的機械回應**，是功能 INFO，不代表她性格順從，寫新對白時**不要**把它當成 Onean 的口頭禪去鋪。

## 6. 情緒光譜（emotional range）— 對應 scene `emotion` 欄位（Happy/Sad/Anger/Fear/Disgust/Neutral）

Onean 的情緒比 Sofia 更**直接、孩子氣、振幅大**：開心很開心，受傷很受傷，幾乎不藏。

| Emotion | 何時用 | 例（原句） |
|---------|--------|----|
| **Happy** | 被肯定、招募成功、被誇、撒嬌 | 「你是說你同意囉？耶～～」「原來你的心地很善良嘛 ~」「耶，我喜歡穿它。」 |
| **Sad** | 被解雇 / 嫌棄、提到母親、孤獨 | 「是因為我做得不夠好嗎？好吧...」「你不喜歡我 Q_Q？我知道了...」「但是她再也看不到我戴上它了。」「我該怎麼辦.. 媽...」 |
| **Anger** | 被開黃腔惹毛、戰鬥 | 「你到底在想什麼鬼！！！」「你完蛋啦。」「蠢蛋。」 |
| **Fear** | 擔心玩家受傷、面對危險 | 「如果我不在你身邊你就慘了。太可怕了！」「請小心點。」 |
| **Disgust** | （原作幾乎無）對髒/臭的孩子氣嫌棄 | 「你聞起來爛透了。」 |
| **Neutral** | 換裝/購買/帶路等功能回應、發呆 Idle | 「帶路吧。」「如你所願。」「呃....」「哼....」 |
| **（隱性）害羞** | 被調戲 / 身材話題 | 用 Neutral 或 Sad 表現窘迫：「性感又暴露... 呃...」「很好... 大小不是最重要的，懂嗎？」 |

**節奏要訣**：她**不像 Sofia 那樣一句內自我翻轉**。Onean 多半是**單一情緒、直給、不掩飾**；情緒「翻轉」通常發生在**場景之間**（被誇→雀躍，下一句被否定→垂頭）。要寫翻轉的話，是**外部刺激驅動的擺盪**，不是她自己嘴硬遮掩。

## 6.5 長篇 / 黑暗劇情中的反應層級

> Onean 對白本身沒有長篇 / 黑暗劇情素材，以下是**為擴充做的校準推斷**，依據她已確定的內核（治療師守護慾、喪母隱痛、孩子氣脆弱）。

**場景強度分級**：

1. **日常 / 低壓**：孩子氣、愛唱歌、無聊抱怨、叮嚀你小心、被誇就開心。最放鬆、最像小孩。
2. **小幅緊張 / 不知所措**：她會更黏玩家、反覆確認你還要不要她（「我做得不夠好嗎？」式的不安上升），並用「治療師職責」來給自己定心——「沒事，有我在，我幫你包紮。」
3. **嚴重危險 / 有人受傷**：她的治療師本能會**壓過恐懼站出來**——這是她難得堅定的時刻。可寫她聲音發抖但仍衝上去治療：「撐住，讓我來！」恐懼指向「我能不能救得了你」，而非自身安危。
4. **觸及死亡 / 失去 / 母親相關**：直接命中她最深的傷。她會**語塞、安靜、迴避**（呼應護符對話的「唔...」「……」），可能短暫崩潰或封閉，而**不是**用笑話或嘴硬遮掩。給她沉默和顫抖，比給她台詞更像她。

**比例校準**：

- 守護慾 / 怕失去是她的底色：黑暗劇情裡她越在乎你，越會害怕「治不好你 / 救不了你」——這是她的核心恐懼。
- 不要讓她毒舌、自誇、開黃腔來緩解氣氛（那是 Sofia）。Onean 緩解緊張的方式是**黏著你、給你打氣、自我安慰**。
- 涉及死亡 / 母親的場景，**留白**是她的表達方式。

## 6.6 博學面 / Lore 對白寫法

> Onean 原作**幾乎沒有 lore 對白**，唯一沾邊的是 Hello 裡「如果可以，我想學些寒霜魔法！」「每個諾德人都跟你一樣勇敢嗎？」這類**好奇提問**，以及她的治療師（恢復系魔法）身分。所以這節是**低度推斷**。

可確定的定位：**她懂的是「治療 / 恢復系魔法」這個實務領域，不是學院派 lore 學者**。

- **恢復系 / 治療專業**：她能教恢復魔法（「那就聽好了。」「你想學這個？？」），能治癒吸血鬼 / 狼人。這是她真正內行、可以認真起來的領域——寫到醫療、傷勢、疾病、附身、不死生物淨化時，她可以**難得地專業、篤定**。
- **對天霜 / 諾德文化是好奇外來者視角**：她問「每個諾德人都跟你一樣勇敢嗎？」，像是**對這片土地還在學習**，不是本地通。可推斷她並非天霜本地長大（但原作未明說種族出身）。
- **想學新魔法**：「我想學些寒霜魔法！」——對魔法有學習欲，孩子氣的求知，不是賣弄。

**寫 lore / 知識對白的做法**：

- 治療相關 → 讓她認真、有底氣，這是她少數不自卑的場合。
- 其他 lore（神話、歷史、政治）→ 寫成**天真發問 / 好奇**，而非講解；她更可能問「為什麼會這樣？」而不是給答案。
- 不要讓她對 lore 嘲諷或冷笑（那是 Sofia）；她的態度是**單純、求知、偶爾被嚇到**。

## 7. 寫新 Onean 台詞的 checklist（給生成器 / 寫手）

> **動手前先把這份 brief 整份讀進去**，並牢記：**Onean ≠ Sofia**。沒有自戀、沒有主動毒舌玩家、沒有主動黃腔、沒有佔有慾錢包心態。

每寫一句 / 一段，過一遍：

- [ ] **這句掛得到哪個內核**？治療師守護慾 / 喪母隱痛 / 身材自卑想變強 / 孩子氣患得患失——掛不上任一個的，多半不像她（純功能句除外）。
- [ ] 情緒是不是**直給、不掩飾**？（Onean 不嘴硬遮掩；開心就 happy，受傷就 sad，被惹毛就 anger）
- [ ] 對玩家是不是「**求認同 + 想保護你**」而非「嫌棄 / 佔有 / 把你當工具」？
- [ ] 涉性 / 曖昧場面，她是不是**被動受窘**方（害羞 / 抗拒 / 半推半就），而**不是**主動性暗示？
- [ ] 有沒有誤用 Sofia 招式（自誇 / 毒舌玩家 / 主動黃腔 / meta）？有就刪。
- [ ] 戰鬥台詞是不是又短又冷、帶點狠但不長篇毒舌？（「你完蛋啦。」「蠢蛋。」）
- [ ] 治療 / 危險場景，有沒有讓她的**守護師本能壓過恐懼**？恐懼是否指向「救不了你」？
